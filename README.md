# Hold releases

Download page and update feed for Hold, a push-to-talk dictation app for Mac.

- Latest installer: the DMG attached to the newest release on the Releases page.
- Updates: the app checks the appcast attached to each release and updates itself.
- Install: open the DMG, drag Hold to Applications, open it, allow Microphone and Accessibility when asked, then paste your relay address and token into Settings.

This repository holds installers, the appcast and release notes only. No source code lives here.
